# Warsha Direct — Landing Page Designs

مقترحات تصميم جديدة لصفحة الهبوط في ورشة دايركت.

## الملفات
| الملف | الوصف |
|---|---|
| `showroom-v2.html` | **التصميم المعتمد**: صفحة كاملة تفاعلية (عربي RTL، داكن) |
| `showroom-v2-improved.html` | نفس شكل v2 بعد تنظيف مخالفات Hallmark: بدون تدرج أزرق بنفسجي، بدون عناوين صغيرة إنجليزية فوق الأقسام، بدون إيموجي أو نقاط زخرفية، والمحتوى يظهر حتى بدون JavaScript |
| `showroom-preview.html` | النسخة الأولى من اتجاه Showroom |
| `screenshots/` | لقطات كاملة: كمبيوتر 1440 وجوال 390 (دقة ×2) لكل قسم + الصفحة كاملة |
| `assets/` | صور المنتج والشعارات والنماذج المستخدمة في التصاميم |
| `canvas/` | لوحات Claude Design للاتجاهات A–D (`*.dc.html` + `canvas.json`) |
| `tools/screenshots.py` | سكربت إعادة التصوير بـ Chrome |
| `_frame.html` | إطار بعرض 390 يُستخدم لتصوير الجوال |

## التشغيل محلياً
```
python -m http.server 4310
```
ثم افتح http://localhost:4310/showroom-v2.html

إعادة التصوير (والسيرفر شغال):
```
python tools/screenshots.py <absolute-output-folder>
```

## ملاحظات
- النصوص بين `[ ]` تحتاج أرقام وحقائق حقيقية: الإحصائيات، رأي العميل، أسعار التقدير، خطوات التسجيل، السنة.
- إضافة `?only=<section-id>` للرابط تعرض قسم واحد فقط (للتصوير).
